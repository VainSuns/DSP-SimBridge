## 2. Verification status definitions

| Status | Meaning |
| --- | --- |
| `已通过静态审核` | 当前源码、生成器或文档已按冻结需求检查；不表示已执行 CCS 或硬件。 |
| `已通过 PC 测试` | 当前仓库的 MATLAB、Host C、protocol、Mock 或 PC 测试存在实际通过证据；具体 runner count 只在集中证据边界记录。 |
| `已通过 PC/Host 测试` | Host fixture 验证了软件机制；不替代目标编译器或实机。 |
| `待用户 DSP 编译` | 实现和集成材料存在，但需要用户 CCS/C2000 compiler 的实际 build log。 |
| `待用户实机验证` / `USER_VALIDATION_PENDING` | 需要用户 TMS320F28377D、W5300、网络或手工 Simulink 联机证据。 |
| `NOT_EXECUTED / CAPABILITY` | 本次环境缺少所需能力，项目未执行；不是 production failure，也不是 PASS。 |
| `约束已落实` | 范围、非目标、责任或变更控制已在当前实现/文档中落实。 |
| `文档已完成` | 对应 Stage 5 文档已完成；不表示文档中的用户步骤已经执行。 |

组合状态保持证据层级。例如“已通过 PC/Host 测试；待用户实机验证”表示软件机制已有证据，但硬件结论仍为 pending。
